# Security Policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/jeffwnelson/pfsense-pkg-speedtest/security/advisories/new)
rather than opening a public issue. Include the package version, pfSense
version, and steps to reproduce. You should get a response within a week.
